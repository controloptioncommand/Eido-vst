## v1 — первая версия

**Приборы**
- Scope, Waves и Spectrogram — виды волны из Mist
- Spectrum: наклон 0 / 3 / 4.5 дБ/окт, под курсором уровень, частота, нота и центы
- Loudness: пики L / R с удержанием, Momentary, Short-term и Integrated по EBU R128
- VU: стрелочный, 0 VU = −18 dBFS
- Stereo: полярный стереометр и корреляция −1…+1

**Окно**
- Режимы Strip (полоса) и Grid (сетка 3 × 2), размер запоминается для каждого
- Шесть слотов: стрелки ‹ › переставляют модуль, ▲ — меню модуля
- Пауза и сброс измерений в тулбаре
- Темы Oxygen и Rubber, шрифты Medeo, пиксельный логотип

**Установка**
1. Скачайте `Eido-macOS.zip` ниже и распакуйте
2. В Терминале: `bash ~/Downloads/Eido-macOS/install-mac.sh`
3. Перезапустите DAW и пересканируйте плагины
